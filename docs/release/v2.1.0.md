# 银杏 v2.1.0

发布日期：2026-09-01

## 主要更新

- 应用启动图标、圆形图标、前景图标、通知图标、GitHub README 与官网图标全面统一为新银杏图标，并移除旧图标引用。
- 微信视频主动拨打从三条入口扩展为六条可组合路线：当前聊天、历史视频记录、最近消息、通讯录、搜索、聊天信息。
- 每进入可靠的新页面都会重新比较安全入口的剩余操作数；发现更短且未失败的入口时立即换线。
- 历史记录失败可切聊天菜单，最近消息失败可切通讯录，通讯录未找到可切搜索，聊天菜单失败可切聊天信息与联系人详情。
- 补强微信当前版本的联系人详情标题、通讯录节点边界、首页标签稳定确认和聊天信息页识别。
- README 增加六路线、逐能力验证、局部换线、身份校验和真实呼叫确认等工程细节说明。
- 手机端“版本详情”同步展示六路线、动态最短入口、自动换线和品牌图标更新。

- 动态最短路线验证：原计划聊天信息长路线，进入聊天页发现已确认的 `[视频通话]` 记录后改走一键入口。
- `790 tests, 0 failed`。
- Android Lint、Release 构建、官网与图标契约测试通过。
- Release APK 通过 APK Signature Scheme v2 签名校验。

## 边界

- 微信来电自动接听不在本版本交付范围内。
- 微信聊天页的历史气泡结构树不暴露消息语义；只有首页已确认目标会话预览为 `[视频通话]` 时才使用历史记录捷径，不根据空白气泡猜测。
- 无障碍自动化仍会受到微信版本、Android 版本和厂商 ROM 的影响，失败时会安全停止并保留脱敏诊断证据。
