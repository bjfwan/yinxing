# 🍂 银杏 v2.3.0 发布

发布日期：2026-10-13

📲 界面改版：设置、联系人、视频通话、应用管理等页面按统一设计规范重构，色彩语义、圆角、字号全面统一。

🌤️ 天气定位重构：定位链路重写为三路并行竞速（系统 provider、WiFi/基站指纹 beaconDB、IP 双源兜底），几秒内返回结果；内置全国省市区县索引（3240 条含坐标），城市搜索支持模糊匹配、错别字纠正、省市拼接写法与简称；定位失败与天气获取失败分开提示。

📱 机型修复：修复部分小米手机定位回调崩溃与来电弹窗异常，建议小米/红米用户尽快更新。

🎥 微信视频：识别“微信未登录”与权限申请页面并明确提示，界面读取异常时自动重新拉起恢复。

🔐 隐私选择：新增“定位数据贡献”开关（设置 → 高级设置，默认开启可随时关闭），真实定位成功时匿名向公共定位库 beaconDB 上报 WiFi/基站观测，让自己和其他人的定位更准；IP/过期缓存结果标注“位置可能有偏差”；隐私政策与服务条款已同步说明。

🛠️ 稳定性：来电服务异常保护增强，息屏误报减少；应用内更新安装前校验 APK 签名，签名不匹配时保留备份到公共下载目录，不再卡死。

✅ 工程验证：`862 tests`（1 例已知 Robolectric 并发 flaky，与本次改动无关）；Release 构建通过；Release APK 通过 APK Signature Scheme v2 签名校验。

📦 APK 大小：约 2.89 MiB；SHA-256：`67001b58879a827878f6ce38ea37bb7668d50199a4879f2700bf461039425ae6`。
