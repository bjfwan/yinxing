# 银杏 v2.0.0

银杏 2.0 是一次完整的产品与工程升级，重点提升长辈使用时的清晰度、稳定性和家属维护效率。

## 主要更新

- 升级主页、家属设置、电话联系人和视频联系人界面。
- 电话联系人支持头像编辑、列表/宫格布局、系统通讯录导入和直接拨号。
- 新增应用内天气详情、城市管理、当前位置、缓存与失败回退。
- 系统电话接听迁移到默认电话角色与 `InCallService`，补充倒计时、状态确认和厂商设置引导。
- 增强微信视频主动拨号的任务恢复、超时处理和故障诊断。
- 清理旧页面、孤立代码和未使用资源，并按功能整理资源文件。

## 兼容性说明

- 支持 Android 7.0 及以上版本。
- 系统电话自动接听依赖默认电话角色和设备 ROM 支持，仍会继续扩充真实 SIM 与多机型验证。
- 微信视频来电自动接听不在本版本交付范围内。
