# 🍂 银杏 v2.5.0 发布

发布日期：2026-10-31

> 说明：自 v2.4.0 起源码不再公开。仓库中的源码停留在 v2.3.0，GitHub 自动生成的 `Source code` 附件为该快照，不含本版本程序源码。APK 继续免费提供并承诺永不收费，详见 [LICENSING.md](../../LICENSING.md)。

本版新增**微信语音 / 视频来电自动接听**，并补齐通话声音辅助、首页卡片开关、联系人批量设置等能力。

📞 **微信来电自动接听（新功能，默认开启）**：微信语音或视频来电时自动接听，只接一对一，群呼叫不接。设置里可单独关闭，接听倒计时 1～30 秒独立保存，不影响系统电话的设置。需要通知访问与无障碍权限，缺权限时设置页会显示「未就绪」并引导，不会静默失败。

🔋 **新增后台保活开关**：微信自动接听开启时，「来电与接听」页多一个「后台保活」，打开后银杏常驻后台并在通知栏显示「微信来电自动接听已开启」，减少系统回收导致接不到；关掉开关通知一起撤掉。

🔊 **通话声音辅助（新功能，默认开启）**：接听或拨打系统电话、接听微信来电、发起微信视频通话时，自动把通话音量调到最大并尝试开免提。使用有线耳机、蓝牙或 USB 耳机时保持原输出，不会强行外放。设置里可随时关闭。

📱 **首页内置卡片开关**：电话、微信视频两个内置卡片可分别隐藏。首页至少保留一张卡片，关掉最后一张会被拦下并提示；最后一个应用被卸载导致首页为空时，会提示「请添加一个应用」并一键进入选择应用。

👤 **联系人整卡可拨打**：电话联系人与视频通话联系人都可设置「点整张卡片即拨打」，减少老人找小按钮的困难；关闭后只有拨号按钮可点，避免误触。管理模式下支持「批量设置」，只改自动接听与整卡可拨打，头像、置顶和拨打次数不会丢。

💬 **反馈入口前移**：设置页顶栏右侧新增反馈图标，不用再翻到「关于银杏」三层里找。弹窗按家属的使用习惯重做：接听不灵 / 界面问题 / 其他三颗类型标签，写一句话就能提交，只上报这段描述与机型信息。

🧾 **关于页新增「特性」页签**：当前版本单独一张重点卡，按新增 / 优化 / 删除分段展示；历史版本收进「历史版本」入口，点开才是版本列表与单版明细，不再把每个版本平铺成长列表。

🔔 **新增条款更新提醒（v2.4.1 及以前没有这个能力）**：以前条款改了用户不会知道。现在隐私政策或服务条款有新版时，设置首页「关于银杏」亮红点，关于页 tab 下方出现「隐私政策已更新，点这里查看」。文档生效日期由官网 `update.json` 的 `legal` 字段下发，改条款不必等发版；打开文档即记为已读，提示自动消失。

🏠 **接完电话回到银杏**：微信语音 / 视频或系统电话挂断后自动回到银杏桌面，不停在微信聊天页或通话页。该能力自 2.4 起已有，本版补强返回判定并记录排查日志，方便定位「挂断后没回桌面」。

🆕 **「新」角标补齐**：角标机制自 2.4 起已有，本版把微信来电自动接听、微信接听倒计时、通话声音辅助三条新增设置项登记进 `NewFeatureRegistry`，右侧标「新」，看过一次即消失；顺带修掉长标题把角标挤出可见区的问题。

🧹 **清理缓存**：清理完成后入口卡片上的数字立即刷新，不再残留旧值；没有可清理内容时显示「暂无可清理」。

☎️ **系统电话稳定性**：规范化完整号码授权、拒接优先、服务统一倒计时，并加入脱敏通话诊断。

🌤️ **天气数据源**：收敛为 Open-Meteo 单一数据源，移除心知天气与腾讯天气。

📊 **诊断**：微信自动接听在正式包里也会记录阶段事件（发现、派发、接通、免提结果、失败原因），同样的失败原因每通只上报一次。只记录事件与相对时间，不采集姓名、号码、聊天内容或通知原文，服从设置里的「诊断日志上报」开关。

✅ 工程验证：`1112 tests, 0 failed, 0 skipped`（192 个测试类，连续两轮一致）；`lintRelease` `0 errors`；Release 构建通过，APK 通过 v2 签名校验。

📦 APK 大小：3.07 MiB（3,219,302 字节）；SHA-256：`8e00d4c16cf374505ff5ef38d395ed91bbe7ee4ada9ef7b2cce4fce0fb226ff6`。

⚠️ 验证边界：微信自动接听在 vivo V1938CT（Android 10、微信 8.0.79）完成真机验证——按「只用正式开关、不开启任何监听试验」的路径连续测试 6 通语音/视频来电，全部接通并正常返回首页，免提在接通后 1 秒内生效。**息屏/锁屏场景、其他厂商 ROM、更多微信版本尚未验证**，这些场景出现问题属于已知边界，会在后续版本继续补齐。
