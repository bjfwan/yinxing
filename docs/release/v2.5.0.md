## 微信来电自动接听转正

📞 **微信语音 / 视频来电自动接听**：从实验能力转为正式能力，正式包默认开启、可在「设置 → 来电与接听」关闭；只接一对一，不接群通话。通知打开来电页、共享电话等待、计时增长确认接通并尝试免提；不输入数字锁屏密码。接听链路新增离屏保活与残留任务丢弃，修掉「第一次能接、后面几通不接」。

🔊 **通话声音辅助**：银杏接听或拨打系统电话、接听微信来电、发起微信视频通话时，自动把通话音量调到最大并尝试打开免提。使用有线耳机 / 蓝牙时保持原输出，免提失败如实记录。可在「接听行为」关闭。

📵 **挂断后回首页**：银杏发起的系统电话与微信通话结束后一次性返回首页；还在响铃或通话中不抢屏；家属可关闭。

## 设置页重排：从 11 个二级页到 8 个

🧭 **分组重排**：概览从「通话与联系人 / 桌面与外观 / 权限与后台 / 系统与更新」四组 11 页，改为四组 8 页——**通话与求助、桌面与外观、权限与更新、高级与关于**，每组两项，深度统一为两层。

🔐 **权限与后台合并为「权限与运行」**：原来「权限管理」和「后台运行」是同一个问题（为什么用不了）的两半，家属得逐页翻才能拼出全貌。现在 8 项分三段（来电识别 / 视频通话 / 后台与默认应用），页面顶部常驻一句「还缺 N 项：…」，不用逐行读徽章。

🤝 **安全守护并入「联系人与求助」**：跌倒检测、紧急联系人本来就是「出事时找谁」，和联系人同属一件事，不再单独占一页。

🎛️ **「高级设置」独立成「高级与数据」**：低性能模式是性能、诊断与定位是数据，原来却挂在「显示与外观」下面第三层。现在独立成页，并收编原来放在「桌面与首页」的开屏广告跳过——那是自动化能力，不是桌面布局。

🖼️ **「卡片大小」不再单独占一层**：原来要「显示与外观 → 卡片大小 → 每个入口」点三次、读一串文字才能调首页上的一个方块。现在卡片与图标大小作为「显示与外观」的第二段直接可见。

🌤️ **天气页取消**：只有一项设置的页面不再单独存在，天气城市收进「桌面与首页」的「桌面行为与工具」段。

📖 **关于页取消标签页**：项目 / 为什么这样设计 / 使用条款三段一次性平铺，不再点 4 次才看得完；「版本特性」（更新日志）移到「系统与更新」，和版本更新放在一起。

🎓 **微信视频示教移到「来电与接听」**：它是微信自动接听的前置配置，不是一条并列功能，现在紧跟在开关下面。

🧾 **显示与外观页收敛文字**：删掉「为每个入口选择大小」整行静态说明（40 字），「统一大小」的解释收进 (i) 点击展开，图标大小副标题精简为当前值——整页只留会变的状态值，解释按需展开。

⏱️ **接听等待改常用档**：系统电话与微信来电的接听倒计时不再是在 1~30 里翻数字，点开就是 3 / 5 / 8 / 10 秒四档加「自定义」竖排大行，当前值直接标在对应档位上（不在四档内则标在自定义上），选完立即生效。真机走查后由横排小卡改为竖排行：横排会把「10 秒」「自定义…」挤成两行、徽章参差。

🎚️ **外观模式行内直切**：「显示与外观」页的外观模式行尾直接放「随系统 / 浅色 / 深色」三段按钮，想切哪个点哪个，一步到位、当前状态常显，不再进弹窗；切换后页面停在原地。按下有涟漪反馈、点击即高亮；深浅两套主题色分别校准对比度。

📐 **系统与更新页行高收敛**：「版本特性」行原来 22 字副标题换行 + (i) 说明图标，整行约 100dp，是同页其它行（56dp）的近 2 倍；真机实测普通设置行 56dp、带 (i) 行 84dp。改为单行「当前 vX · 共 N 项变化」+ 只保留箭头，删掉与箭头重复的 (i)（`settings_version_features_info` 一并移除），整页 4 行统一 56dp；信息只减重复、不减内容，版本历史入口照常可用。

## 防呆与状态可信

⚠️ **未就绪提示**：默认开启但缺系统能力的功能（微信自动接听、开屏广告跳过）在页面顶部与行内明确标出缺什么、点哪里去修，不再出现「开关是开的、其实不生效」而用户以为是功能坏了。

🧾 **配置清单合并**：「家属配置清单」和「使用前检查」原来是两套清单、两个说法（首启说 2/2 可以交给老人，使用前检查说还缺 N 项，电话权限两边都算）。现在合成**一个入口 + 一页清单**：必要设置（常用联系人、电话权限）决定能不能交给老人，默认桌面是推荐项，使用前检查只列缺项、已完成折叠成一行，点缺项直达系统设置、回来自动刷新。原「使用前检查」弹窗删除——8 项长清单不再用弹窗承载。首次启动保持精简：只常驻必要设置，使用前检查默认折叠，必要 2/2 才放行「进入老人首页」，其余可以进首页后再配。

🧹 **清理缓存就地执行**：不再给「下一层」箭头，点击直接执行并在行内回显可清理大小，清完自动重算。

🔄 **就绪判定收口**：首页横幅、设置概览、设置详情、微信视频页原来各写一遍「无障碍到底能不能用」，现在统一成一个入口；系统开关开着但服务被系统杀掉时，一律判为不可用（vivo / iQOO 最常见）。

## 其它

📝 **设置页反馈入口**：顶栏右侧新增图标，三颗类型标签 + 一句话描述，只上报描述与机型信息，不含联系人、号码与聊天内容。

🏷️ **新功能「新」角标**：按版本登记，进入一次即消隐，版本基线自动翻页。

📜 **条款更新提示**：官网 `update.json` 声明隐私政策 / 服务条款生效日期，比本地已读新时在「关于银杏」显示提示；打开文档即记为已读。

🧩 **首页内置卡片开关**：电话、微信视频两张内置卡片可分别隐藏；首页至少保留一张，关到最后一张时拦下并提示。

📇 **联系人整卡可拨打**：联系人级开关 + 管理态批量设置；原设置页全局「整卡可点击拨打」开关移除。
