# 微信能力树与通话结束返回桌面迁移规格

## 目标

- 微信自动拨号从服务内固定步骤迁移为“语义能力接口 + 轻量行为树备用路线”。
- 银杏发起的系统电话或微信视频结束后，一次性返回银杏首页。
- 删除旧的坐标/控件路径回放执行器；旧数据只允许迁移或诊断，不能再接管点击。

## 产品边界

1. V1 只处理从银杏电话联系人、银杏微信视频联系人发起的外拨。
2. 普通手动通话、来电、跌倒求助电话、用户主动切到其他应用均不自动返回。
3. 通话必须先被系统 `ACTIVE` 或微信 `VideoActivity` 确认；拨号失败、误入语音通话不触发返回。
4. 返回只执行一次，目标固定为银杏首页；会话超时、进程重启或出现新通话时自动作废。
5. 家属设置提供“通话结束回到银杏首页”开关，建议默认开启；关闭后完全不建立返回会话。

## 接口与行为树

- `WeChatCapability`: 前置状态、执行、结果状态、失败原因，不保存任意页面文字。
- 能力：启动微信、最近消息、历史视频记录、通讯录、搜索、聊天信息、联系人详情、目标校验、音视频菜单、视频选择和通话启动确认。
- 行为树：
  - `Sequence(Fallback(当前聊天, 历史视频记录, 最近消息, 通讯录, 搜索, 聊天信息), 打开视频入口, 选择视频, 确认启动)`
  - 每个能力执行后重新观察和校验；失败只切换下一个备用路线，不重跑整条链路。
  - 每进入一个可靠的新页面，都重新比较当前可用且未失败入口的剩余操作数；聊天页按“历史视频记录 1 步、聊天菜单 3 步、聊天信息 4 步”选择最短入口，不受之前计划路线约束。
- 首页标签必须连续两次观察为 `selected` 后才能点击列表，避免读取标签切换前的旧节点树。
- 历史视频记录只在目标会话预览为 `[视频通话]` 时启用；仅点击输入框上方最低的可见消息气泡，未进入 `VideoActivity` 即退回聊天菜单。
- 聊天菜单不可用时，经聊天信息页的目标联系人名称进入联系人详情；任何路线都不使用裸坐标直接拨号。

## 通话返回会话

- 发起前建立带 `origin/requestId/ttl` 的一次性会话。
- 系统电话由 `InCallService` 的 `ACTIVE -> DISCONNECTED/onCallRemoved` 完成会话。
- 微信由无障碍服务确认进入 `VideoActivity`，随后稳定离开通话页并回到微信页面时完成会话。
- 若期间观察到用户切换到非银杏、非电话、非微信应用，则标记 `userEscaped`，结束后不抢回首页。

## 迁移与删除

1. 用契约测试固定现有成功链路，再接入能力树；先保持“最近消息 + 搜索”行为不变。
2. 示教只沉淀能力选择器校准和未知能力候选；验证统一调用新能力树。
3. 删除 `tryStartTeachingRouteFallback`、`executeAutomationTeachingRoute`、`executeTeachingRoute` 及原始步骤回放入口。
4. `routes_v2` 不再读取或执行；清除示教和重置操作会删除残留键。诊断上传模型不得提供执行入口。
5. 删除旧 codec、policy、playback 及对应测试；LogAnalyse 保留旧记录可读，新数据改为能力 ID、页面状态、执行结果和失败原因。

## 验收

- OPPO：银杏电话外拨挂断、微信视频取消/挂断后均回银杏首页。
- 普通来电、微信手动拨打、跌倒求助、通话中切到其他应用均不抢回首页。
- 最近消息失败依次切通讯录、搜索；历史记录失败切聊天菜单；目标身份未验证时不得点击拨号。
- 原计划长路线但新页面出现更短的安全入口时立即改走短路线；已经失败的入口不得被重新选择。
- 全仓搜索不存在旧回放运行入口；微信定向测试、电话定向测试和 Debug 构建通过。

## 已确认

- V1 只覆盖银杏发起的外拨。
- 设置开关默认开启，家属可关闭。
