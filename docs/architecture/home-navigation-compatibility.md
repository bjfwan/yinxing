# 首页返回与厂商兼容策略

## 目标

优先使用 Android 正式的默认桌面能力。只有系统不允许或实际不生效时，才由用户主动选择兼容方案。

| 厂商 | 首选方案 | 可选回退 |
| --- | --- | --- |
| vivo / iQOO | 默认桌面 + 系统“允许更换桌面” | Home 辅助返回 |
| OPPO / realme / OnePlus | 默认桌面 | OPPO 兼容组件；Home 辅助返回 |
| 小米 / Redmi / POCO | 检查系统是否开放默认桌面 | Home 辅助返回 |
| 华为 / 荣耀 | 按系统版本检查默认桌面 | Home 辅助返回 |
| 三星及标准 Android | 系统默认桌面 | 通常不需要回退 |

## Home 辅助返回

- 所有厂商均可见，默认关闭，必须由用户主动开启。
- 仅监听已知系统桌面的首页 Activity；设置页、最近任务页和未知桌面不触发。
- 有 1.5 秒冷却，避免重复拉起。
- 标准系统已确认银杏持有 Home 角色时不执行；ColorOS 曾出现“角色已持有但 Home 仍进系统桌面”，因此以实际系统桌面事件作为补充判断。
- 依赖无障碍服务，适合作为回退，不替代正式默认桌面。

## OPPO 兼容组件

- 仅在 OPPO、realme、OnePlus 设置页展示，用户确认后才交给系统安装器。
- 包名为 `com.android.cts.robot`，用于匹配已验证 ColorOS 兼容名单；组件本身无代码、无权限、无入口。
- 使用公开 AOSP testkey 签名，不在仓库保存私钥。内置 APK 的 SHA-256 为 `105C3892022839C5D880006C63DBF0AD2EFE89832BFC58873ECA2CD6B6CF2DAA`，运行时校验后才安装。
- 系统更新后可能失效；设置页提供卸载入口。安装失败时仍可选择 Home 辅助返回。

## 已知边界

厂商云测通常会限制默认桌面、无障碍、重启或安装外部组件。该链路必须在对应厂商真实零售机上完成最终确认。
