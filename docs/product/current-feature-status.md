## 当前收尾边界

- 首页视觉仍由产品侧继续调整。
- 系统电话自动接听需要真实 SIM、不同 Android 版本与厂商 ROM 回归。
- 默认桌面成功判断需要同时校验 `RoleManager` 与系统实际 HOME 解析结果；OPPO 状态不一致时应提示继续设置，不能显示成功。
- 本轮尚未完整重跑 `connectedDebugAndroidTest`。
- 当前仍有 85 条非阻塞 Lint 建议，主要是 API 现代化、KTX、无障碍描述和少量文本规范。

## 状态口径

- “已实现”表示主流程已存在并通过当前自动化基线，不等同于所有机型已验证。
- “已验证”表示指定真实设备上的业务路径曾跑通，兼容性范围以记录为准。
- “软件适配完成，真机待扩充”表示代码链路已具备，但不能替代真实 SIM 与多 ROM 验证。
- “不在当前交付范围”表示明确暂缓，不应出现在本版本完成承诺中。
