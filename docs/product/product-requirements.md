# OldLauncher 产品需求说明

更新时间：2026-10-28
状态：当前发布版本事实说明（`2.4.1` / `versionCode = 23`）

## 1. 产品定位

- 类型：Android 本地桌面启动器
- 目标用户：需要更简单手机主页的老年用户
- 技术边界：无账号、无业务后端，核心数据本地优先
- 当前目标：把常用应用、电话联系人、视频联系人与基础系统入口收拢到一个更易操作的主页中

## 2. 当前版本目标

- 提供可作为默认桌面的主页
- 提供清晰的大图标入口和时间日期展示
- 允许家属或维护者选择桌面展示哪些应用
- 提供可直接拨号的电话联系人管理能力
- 提供可独立维护的视频联系人页
- 提供微信视频入口与自动化拨号能力，并持续强化稳定性、可恢复性和诊断能力
- 当前发布版本为 `2.4.1`（versionCode 23）

## 3. 当前已纳入范围

### 3.1 桌面主页

- 支持 `HOME` 和 `LAUNCHER` 入口
- 桌面展示时间、日期、农历和常用入口
- 内置大卡仅包含：电话、微信视频；两者使用大号绿色圆角方形功能图标，不使用圆形图标底板
- 顶部白色信息卡集中展示时间、日期、农历和天气，并作为天气详情入口
- 底部固定“调整首页”按钮进入应用管理
- “家属设置”位于顶部右侧，集中承载联系人、权限与系统配置
- 六格网格下，首页入口支持小（一行三个）、中（一行两个）、大（独占一行）三档卡片大小，可按入口单独设置或统一设置；档位混排时剩余格均摊给本行，不留行尾空隙
- 使用前检查卡集中展示来电链路（通知 / 默认电话 / 电话权限）、视频链路（无障碍 / 悬浮窗）与保活（电池 / 自启 / 后台）三条执行条件，未就绪时给出跳转引导
- 设置条目对新功能显示「新」角标，家属设置入口有提示引导
- 支持把已选择的第三方应用展示到桌面
- 在桌面按返回键时提示“已经是桌面了”

### 3.2 应用管理

- 提供应用列表页面
- 支持通过勾选把应用加入桌面
- 支持取消勾选后从桌面移除
- 当前使用本机 Launcher 应用列表进行选择

### 3.3 电话模块

- 以应用内本地电话联系人为主
- 支持从系统通讯录读取联系人并导入到本地联系人列表
- 展示联系人头像、姓名、号码
- 支持联系人拨号、新增、编辑、删除和为联系人选择照片
- 当前新增、编辑、删除作用于应用内本地联系人，不回写系统通讯录
- 联系人所有读写操作在后台线程执行，不阻塞主线程

### 3.4 视频通话联系人页

- 提供独立的视频联系人页面
- 支持本地新增和删除视频联系人
- 支持搜索与置顶视频联系人
- 支持按通话次数排序联系人
- 支持发起微信视频，并具备无障碍服务中断兜底、请求级超时、失败回前台和步骤级诊断

### 3.5 天气

- 应用内天气详情与城市管理，不把老人丢到第三方页面
- 数据源为 Open-Meteo，配合磁盘缓存与失败回退
- 当前位置定位三路并行：系统 provider（短宽限等待）、WiFi/基站指纹（beaconDB 公共库）、IP 双源兜底；过期缓存降级为最后兜底并标注“位置可能有偏差”
- 内置全国省市区县地名库（3240 条含坐标），支持模糊匹配、错别字纠正、省市拼接写法与简称
- 定位失败与天气获取失败分开提示，失败时保留原城市
- “定位数据贡献”开关默认开启：真实定位成功时匿名上报 WiFi/基站观测到 beaconDB，可随时关闭

### 3.6 系统电话自动接听

- 默认电话角色 + `InCallService` + `Call.answer()`
- 可调倒计时、实际通话态确认、联系人匹配与厂商设置引导
- 设备不支持直接拨号时自动回落系统拨号盘
- 仍需真实 SIM、不同 Android 版本与厂商 ROM 验证，不承诺全机型一致

### 3.7 通话结束返回首页

- 仅银杏发起的系统电话与微信视频，结束后一次性返回银杏首页
- 识别用户主动离开其他应用时不抢回
- 家属设置提供开关

### 3.8 跌倒检测与紧急求助（实验性）

- 传感器前台服务检测跌倒，全屏提醒 + 误报取消 + 呼叫紧急联系人
- 公开数据离线回放结果与真机效果分开说明，不作为准确率承诺

### 3.9 开屏广告自动跳过（实验性）

- 打开其他应用时保守识别并点击“跳过”按钮，绝不点击广告本体
- 默认开启，家属可在设置关闭

### 3.10 首次家属配置引导

- 首次使用由家属完成默认桌面、联系人和必要权限配置

### 3.11 应用内更新与设备诊断

- 应用内检查、下载、断点续传与多线路自动切换
- 安装前校验 APK 签名；签名不匹配时保留备份到公共下载目录并提示
- 诊断日志上报开关，用户可自主选择；日志与性能指标使用脱敏后的结构化诊断字段

### 3.12 微信视频示教

- 家属人工完成一次微信视频流程，银杏把脱敏控件特征绑定到固定语义动作，形成本机校准资料
- 只校准语义动作，不录制或执行任意动作序列；上传默认勾选、可取消

### 3.13 清理缓存

- 设置内一键清理本应用缓存与临时文件，带大小预估、进度与取消
- 不删除照片、联系人、设置等数据

### 3.14 版本优化记录

- v2.4.0：清理缓存、首页卡片大小、使用前检查、「新」角标、家属入口提示、开屏广告自动跳过、诊断降噪、无障碍健康跟踪
- v2.4.1：联系人/视频管理模式下的交互修复、空状态排版、管理工具卡收紧、软件许可证按版本说明、长内容弹窗滚动修复

## 4. 当前未纳入交付范围

- 微信来电自动接听（当前发行版未交付）
- 系统电话自动接听的全机型稳定性承诺
- 来电风险评估的全机型稳定性承诺（实验性功能）
- 通知监听服务的对外/通用交付
- 后台定时任务
- 远程协助、云同步、账号体系

## 5. 非功能要求

- 兼容 Android 7.0 及以上系统
- 本地存储优先，避免引入服务端依赖（天气与定位使用公共只读接口，不上传身份）
- 日志与性能指标仅用于诊断，不采集账号身份
- 页面风格以浅灰蓝背景、白色卡片、深色文字和绿色主操作为统一基线，唯一设计契约见根目录 `DESIGN.md`
- 首页优先大字体、大图标、清晰层级；主要触控目标不小于 56dp，并适配系统状态栏与导航栏安全区
- 老人高频操作直接可见，配置类操作统一收进“家属设置”或“调整首页”
- 数据读写操作不阻塞主线程
- 目录和文档结构必须可维护

## 6. 当前验收口径

- 相关单元测试可以通过（任务名 `:app:testDeviceTestUnitTest`）
- `:app:assembleDebug` 可以通过
- `:app:assembleDebugAndroidTest` 可以通过
- `:app:lintDebug` 为 `0 errors`
- 主页、应用管理、电话模块、视频联系人页、天气和家属设置可以正常打开
- 主页作为默认桌面后，基础返回和入口跳转逻辑正常
- 文档内容与当前发布能力保持一致
